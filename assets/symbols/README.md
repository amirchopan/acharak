# آیکون‌های Volvo Design System

این پوشه باید حاوی ۳۶ فایل SVG زیر باشد — دقیقاً با همین نام‌ها (kebab-case، مطابق نام‌گذاری کتابخانه‌ی رسمی آیکون ولوو). این نام‌ها را من در کل کد پروژه (`js/app.js`, `js/components.js`, `js/utils.js`) به همین شکل ست کرده‌ام، پس کافی‌ست فایل SVG هر آیکون را با همین نام دقیق داخل این پوشه قرار دهید تا بلافاصله در برنامه نمایش داده شود.

نکات مهم هنگام دانلود از Storybook:
- نسخه‌ی **Outline** (نه Filled) هر آیکون را بردارید — چون آیکون‌ها با `mask-image` و `currentColor` رندر می‌شوند و فقط به شکل (نه رنگ) فایل نیاز داریم.
- `viewBox="0 0 24 24"` باید حفظ شود.
- اگر فایل SVG دارای `fill` یا `stroke` با رنگ ثابت (مثل `#000` یا `black`) بود، مشکلی نیست — چون فقط کانال آلفا (شفافیت) برای mask استفاده می‌شود.
- اگر اسم دقیق یک آیکون در کتابخانه با آنچه اینجا نوشته‌ام کمی فرق داشت (مثلاً یک آیکون حذف/rename شده)، نزدیک‌ترین معادل را با همین نام فایل ذخیره کنید یا به من بگویید تا نام مربوطه را در کد اصلاح کنم.
